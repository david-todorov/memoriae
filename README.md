# Memoriae

Memoriae is a collaborative event and photo-sharing platform currently under development.

The goal is to allow users to create private events and galleries, invite other people to contribute photos, and preserve shared memories in one place.

## Planned Features

- User registration and authentication
- Email verification
- JWT-based authentication with refresh tokens
- Event and gallery creation
- Secure invitation links
- Guest photo uploads
- User notification preferences
- Email notifications
- Image and object storage
- Web client
- Potential Android and iOS clients in the future

## Technology

### Backend

- Java 21
- Spring Boot
- Spring Security
- Spring Data JPA
- PostgreSQL
- Flyway
- Spring Mail

### Infrastructure

- Docker
- Docker Compose
- PostgreSQL
- Mailpit

## Current Status

Memoriae is in early development.

The current focus is establishing the project infrastructure and implementing a secure authentication and authorization system before moving on to events, galleries, invitations, and image storage.
